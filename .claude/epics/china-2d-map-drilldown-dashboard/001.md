# Task: 项目初始化和开发环境搭建

## Description
创建中国地图2D数据大屏项目的基础结构和开发环境配置，包括HTML骨架、项目目录结构、开发工具配置和基础依赖设置。

## Acceptance Criteria
- [ ] 创建标准的HTML单页面应用骨架结构
- [ ] 设置项目目录结构（css, js, data, assets等目录）
- [ ] 配置开发服务器（如Live Server或http-server）
- [ ] 设置基本的开发工具配置（如.gitignore, README.md）
- [ ] 集成ECharts库依赖（CDN或本地文件）
- [ ] 验证开发环境能够正常运行基础HTML页面

- **依赖管理**: 通过CDN引入ECharts库，或下载本地版本
- **基础配置**: 设置meta标签、字符编码、视口配置等HTML基础
- **浏览器兼容**: 确保基础HTML结构在现代浏览器中正常显示
