## Description
实现地级市和区县级地图数据的动态加载和渲染，支持按需加载和缓存策略，确保三级行政区划数据的完整展示。

## Acceptance Criteria
- [ ] 实现地级市GeoJSON数据的动态加载
- [ ] 实现区县级GeoJSON数据的动态加载

## Technical Details

- **缓存策略**: localStorage缓存已加载的地图数据
- **错误处理**: 网络错误和数据格式错误的降级处理
- **性能优化**: 数据预加载和懒加载策略
