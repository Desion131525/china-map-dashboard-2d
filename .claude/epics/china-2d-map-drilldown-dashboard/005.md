# Task: 钻取导航功能和路由管理

## Description
实现省→市→县三级钻取导航功能，包括点击区域进入下一级视图、返回上一级功能，以及基于URL hash的路由管理。

## Acceptance Criteria
- [ ] 实现省级区域点击进入地级市视图
- [ ] 实现地级市区域点击进入区县视图
- [ ] 添加返回上一级的导航控制
- [ ] 实现基于URL hash的路由状态管理
- [ ] 支持浏览器前进后退导航
- [ ] 维护钻取路径的breadcrumb显示

## Technical Details
- **点击事件**: 监听ECharts的click事件处理区域点击
- **视图切换**: 动态切换ECharts地图数据和配置
- **路由管理**: 使用window.location.hash管理导航状态
- **历史记录**: 支持浏览器history前进后退操作
- **状态持久化**: URL可分享和刷新后恢复状态
